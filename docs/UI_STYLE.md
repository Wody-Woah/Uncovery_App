# The Uncovery — UI Style Guide

## Design Goals
- Reflective, calm, and hopeful.
- Inspired by the book cover.
- Feels like reading a printed devotional, not a tech product.

---

## Color Palette

Primary Accent:
- Muted steel blue (#5F7F96 approx)

Secondary Accent:
- Warm sunrise orange (used sparingly for highlights)

Background:
- Warm off-white (not pure white)

Text:
- Charcoal (not pure black)

Muted Text:
- Soft gray for references and dates

---

## Typography

Headings:
- Clean sans-serif (modern but calm)

Body (Devotion Content):
- Serif font for a printed book feel

Verse Text:
- Slightly indented or italic
- Slight background tint or subtle divider

Prayer Section:
- Slight separation from body
- Possibly soft background shade

---

## Layout

- Mobile-first
- Centered reading column
- Max width: 680–720px
- Generous vertical spacing
- Soft card separation (very subtle shadow or border)

---

## UI Elements

Header:
- Simple, minimal
- Accent underline or subtle divider

Buttons:
- Rounded
- Muted blue background
- No harsh hover effects

Cards:
- Light elevation
- Gentle border radius

---

## Emotional Tone

The app should feel:
- Gentle
- Grounded
- Spacious
- Personal
- Encouraging

Avoid:
- Loud animations
- Heavy gradients
- Bright tech colors
- Overly modern dashboard aesthetics
